# AC Infinity Wall Dashboard

Full-screen landscape Android wall display for **AC Infinity Controller AI+** and **Controller 69 Pro**.

![AC Infinity Wall Dashboard](dashboard.jpg)

## Features
* **Dual-Controller Live Telemetry:** Updates every 10 seconds with Temperature, VPD, Humidity, and active port speeds/states.
* **Hydro & Reservoir Rings:** Dedicated `pH`, `EC`, and water `TEMP` rings for Controller AI+ hydro sensors.
* **24-Hour Photoperiod Dials:** Live Sun/Moon schedule arcs with countdown timers (`TO ON` / `TO OFF`).
* **Trend & Alert Indicators:** Target-range ring colors, liquid drip momentum beads, and a bottom-centre 24-hour clock.

## Installation & Setup
1. Download the latest APK from **Releases** (or from the latest successful run under **Actions**).
2. Enable **Install from unknown sources** on your Android tablet and install the APK.
3. Sign in with your **AC Infinity account email and password** (credentials are stored locally on your device only).
4. **To log out:** Tap the small green status dot next to the first controller title **7 times**.
